# AgentUsage 0.5.1

AgentUsage 0.5.1 fixes Codex discovery in the Windows notification-area edition.

## Windows fix

- Finds Codex Desktop's CLI in its versioned `%LOCALAPPDATA%\OpenAI\Codex\bin\<build-id>` installation directory.
- Reads both the inherited process PATH and the persistent user and machine PATH values used by Explorer-launched applications.
- Adds npm, NVM, Windows App Paths, standard local installation directories, and `AGENTUSAGE_CODEX_PATH` as supported discovery methods.
- Improves the missing-Codex diagnostic with the locations AgentUsage checked.

The existing macOS functionality is unchanged.
