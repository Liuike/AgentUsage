# AgentUsage 0.5.0

AgentUsage 0.5.0 introduces a native Windows notification-area edition focused on Codex usage.

## Windows edition

- Adds a dependency-free native Windows tray app with the compact AgentUsage design language.
- Reads Codex limits, plan details, credits, reset credits, streaks, and token activity directly from the authenticated local Codex app-server.
- Includes Day, Week, and Cumulative activity visualizations with hover details and persisted history navigation.
- Supports 5-hour, 7-day, combined-limit, and billing tray metrics with ring, percentage, and combined display modes.
- Adds configurable refresh intervals, Windows light/dark theme support, per-user startup registration, update checking, and single-instance reopening.
- Ships a portable ZIP and a per-user PowerShell installer that requires no administrator access.
- Intentionally omits Claude Code integration from the Windows edition.

The existing macOS application remains unchanged in this release.

## Install on Windows

1. Download and extract `AgentUsage-Windows-v0.5.0.zip`.
2. Run `Install-AgentUsage.ps1` from PowerShell, or launch `AgentUsage.exe` directly for portable use.
3. Ensure the Codex CLI is installed, available on `PATH`, and signed in.
