# AgentUsage 0.5.2

AgentUsage 0.5.2 fixes update checks and improves percentage readability in the Windows notification area.

## Windows fixes and improvements

- Points update checks and release links at the maintained Windows release repository.
- Explicitly enables TLS 1.2 for compatibility with GitHub on older .NET Framework configurations.
- Shows the underlying network error when an update check fails instead of only a generic message.
- Shows an in-progress state while checking for updates and prevents duplicate checks.
- Allows slower Codex account and rate-limit responses to complete instead of failing after four seconds.
- Reads the current Codex account response format while remaining compatible with older Codex versions.
- Reworks Percentage and Ring + Percentage into a wider pill treatment with a larger number and an explicit `%` mark.
- Preserves a progress treatment around the percentage pill in Ring + Percentage mode.
- Removes the app-driven refresh spinner and DWM window transitions on Windows while retaining an immediate static refresh-state indicator.
- Makes Options expansion resize and reposition in place instead of hiding and reopening the panel.
- Removes the rotating refresh animation and the hide/show transition used while expanding Options; refresh and expanded state now update instantly.

The existing macOS functionality is unchanged.
